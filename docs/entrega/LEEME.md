# Entrega KOTTO · UTN La Plata

Integrantes: Ignacio Echave, Amparo Rodriguez y Flavio Sistro.

Archivos de entrega: monografía PDF (18 páginas) y presentación PDF (13 diapositivas). El prefijo SISTRO_FLAVIO asume que Flavio realiza la carga; si carga otro integrante, ajustar el prefijo al apellido y nombre de esa persona. Solo un integrante sube el trabajo.

El ZIP de código es complementario y no contiene base local, cuentas, claves ni capturas. La fuente de la monografía está en monografia.md. Los datos agregados están en resultados.json. Para regenerar ambos PDF, instalar ReportLab y disponer de DejaVu Sans; ejecutar generar_pdfs.py desde Python. Las dependencias de generación de documentos no son necesarias para ejecutar el laboratorio.
